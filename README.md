# Prolog derivation tree component

This repository contains the code for a Prolog derivation tree component. It is completely based on the tau-prolog project. Only `prolog-derivation-tree-component.js` is new.


## Usage

          <prolog-derivation-tree data-program='friend(a, b).
            friend(a, c).' data-goal="friend(a, X).">
          </prolog-derivation-tree>
